# Lunar-Landing-Site-Navigator
Official Repository for NASA Space App's London Virtual Event

Start in Moon Explorer, select one or two landing sites, and open them in Skyline V3.

## Run locally

Install Git, Python 3.10 or later, and Node.js 24. Clone the branch that contains
Moon Explorer and Skyline V3:

```sh
git clone --branch improvement/3D-rendering https://github.com/KrishJ13/Lunar-Landing-Site-Navigator.git
cd Lunar-Landing-Site-Navigator
```

Follow the [backend and frontend setup](docs/moon_explorer.md#run-locally), then
open [Moon Explorer](http://localhost:5173/moon.html).

## Make changes

Create a feature branch before editing. The local development servers reload
changes to the frontend and backend.

Repository collaborators can push their feature branch and open a pull request.
Other contributors can push to their own fork and open a pull request from it.
